## 🏛️ Portfolio Overview

This portfolio website showcases the academic, studio, and research projects of **Faysal Ahmed**, an architecture student in his final year at Daffodil International University. The work focuses on **climate-adaptive urbanism**, **high-density residential frameworks**, **industrial ecology**, and **tactical social infrastructure**.

### Key Projects Featured

1. **Project 01: Korail Agro-Urban Nexus (Cultivating Resilient Communities)**
   - *Typology:* Ecological Community Infrastructure & Urban Agriculture
   - *Location:* Korail Informal Settlement, Dhaka (Spring 2025)
   - *Sheets:* Sheet 01 (Concept & Zonal Layout), Sheet 02 (Masterplan & Agricultural Wind Flow)
   - *Focus:* Multi-tier urban farming (open field, aeroponic, loft, greenhouse), women's vocational hub, nature-based kids play zone, rainwater harvesting, and solar energy.

2. **Project 02: Between Water & Home (Toward an Inclusive & Adaptive Korail)**
   - *Typology:* Waterfront Bio-Filtration & Circular Economy
   - *Location:* Korail Lake Edge, Dhaka (Spring 2025)
   - *Sheets:* Sheet 03 (Circular Waste-to-Craft & Bio-Filter Section), Sheet 04 (Multi-Block Master Plan: Blocks 1, 2, 3)
   - *Focus:* Transforming informal waste (plastics, cables) into artisanal crafts; multi-stratified bio-filtration wetland island (topsoil, subsoil, brick chips, bedrock), floating agricultural beds.

3. **Project 03: Clustered Urban Housing, Uttara, Dhaka**
   - *Typology:* High-Density Residential Masterplan & Housing Campus
   - *Location:* Uttara Blocks C & D, Dhaka (Fall 2025)
   - *Sheets:* Sheet 05 (Campus Masterplan Development), Sheet 06 (1200 & 1600 sq.ft 4-Unit Plans, South Elevations, Section BB')
   - *Focus:* 112-Acre site, 200 people/acre density, only 13% building footprint, 55% green open space preservation, deep shaded south balconies, cross-ventilation.

4. **Project 04: Design of an E-Waste Recycling Factory, Manikganj**
   - *Typology:* Industrial Architecture & Controlled Environmental Zoning
   - *Location:* Manikganj, Bangladesh (Spring 2026)
   - *Sheets:* Sheet 07 (Linear 4-Zone Strategy: Dirty, Processing, Clean, Service), Sheet 08 (Axonometric Breakdown, Solar Roof, Green Bio-Wall, Floor Plans, Sections AA' & BB')
   - *Focus:* Microclimate wind orientation (downwind dirty zone), hazardous e-waste containment, acoustic control, living green wall filters, 15h 26m solar study.

5. **Urban Research Project: Commons Module (Learning from the Lanes of Korail)**
   - *Typology:* Urban Ethnography, Spatial Justice & Modular Kit-of-Parts
   - *Location:* Korail Informal Settlement & Gulshan Boundary (2025)
   - *Sheets:* Poster 01 (Socio-Spatial Disparity Analysis & 8 Crisis Maps), Poster 02 (Kit-of-Parts Modular Interventions)
   - *Focus:* Child Activity Module, Stall & Sitting Module, Community Learning Board for narrow 1m informal settlement alleys.

6. **Heritage Exploration: Time Transitions & Contrasts (Manikganj Teota Jomidar Bari)**
   - *Typology:* Heritage Re-Interpretation & Architectural Phenomenology
   - *Location:* Teota Jomidar Bari, Manikganj (2025)
   - *Sheets:* Board BUC074 (High-Resolution Architectural Board 6496 × 9449 px)
   - *Focus:* Experiential continuum navigating between Past, Present, and Future through an axial transition hallway, monumental stairs, and tactile terracotta masonry.

## ✨ Website Features

- **Architectural Aesthetic:** Modern, minimalist studio design inspired by Swiss typography and architectural drafting grids (`+` crosshairs, coordinates, scale indicators, sheet numbering).
- **Sequential Sheet Presentation Mode (Flipbook / Review Mode):** An interactive mode replicating a portfolio binder review for academic juries and studio hiring managers. Includes full keyboard navigation (`←` `→` arrows, `Esc`).
- **Deep Pan & Zoom Lightbox:** Mouse drag-to-pan and multi-level zoom (100% to 400%) for inspecting fine architectural line weights, annotations, dimensions, and floor plans.
- **Dual Studio Theme:** Toggle between Architectural Ivory/White and Studio Dark Graphite (`Ctrl/Cmd` responsive and persistent).
- **Multi-Category Filter:** Browse by *All*, *Urban & Ecological*, *Residential Housing*, *Industrial & Sustainable*, *Research & Urbanism*, and *Heritage & Spatial*.
- **Comprehensive Project Modals:** Detailed spatial program descriptions, design strategy checklists, and technical data tables.
- **Academic CV & Studio Trajectory:** Progression from Studio VI through Studio IX at Daffodil International University.
- **Collaboration & Inquiry Form:** Interactive contact portal with direct email integration.
- **Performance Optimized:** Includes high-resolution master sheets alongside web-optimized responsive images (100KB thumbnails to 800KB mid-res) for instant page loads.

## 🚀 Quick Start & Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/armanhossen-dev/Portfolio_for_faysal_vai.git
cd Portfolio_for_faysal_vai

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
```

The optimized static files will be generated in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## 🌐 Free One-Click Deployment Options

### Option A: GitHub Pages
1. Go to repository **Settings** → **Pages**.
2. Select **Source: Deploy from a branch** → choose `main` branch and `/dist` or use GitHub Actions.
3. Because `vite.config.js` is configured with `base: './'`, it works seamlessly out-of-the-box.

### Option B: Vercel / Netlify
1. Connect this GitHub repository to Vercel or Netlify.
2. Build command: `npm run build`
3. Output directory: `dist`
4. Deploy!
